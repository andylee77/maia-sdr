## Build Systems

### FPGA Gateware (p25_hdl)

**Tool:** Vivado 2023.2 + Amaranth HDL (Python)
**Target:** Fishball Z7020 (`projects/fishball7020_p25/`)

**Build flow:**

1. Amaranth generates Verilog from Python HDL: `cd ip/p25-core && make`
2. Vivado IP packaging + synthesis: `cd projects/fishball7020_p25 && make`
3. XSA/bitstream packaged into BOOT.bin by Tezuka Buildroot

### PS Firmware (p25-httpd)

**Tool:** Rust + Cross (cross-compilation to ARM)
**Built by:** Tezuka firmware Buildroot (not standalone)

Cross-compiled for `armv7-unknown-linux-gnueabihf` (Zynq-7000).

### SVD Generation

```bash
python generate_p25_svd.py
# Outputs SVD file for svd2rust -> p25-pac
```

### Submodule

```text
ext/maia-sdr/ -> andylee77/maia-sdr (fishball-dev branch)
```

Provides `maia_hdl` Python package: DDC, DMA, registers, spectrometer, recorder, CDC utilities.
ADI HDL library comes via `ext/maia-sdr/maia-hdl/adi-hdl/`.

## DSP Signal Chain

```text
AD9361 IQ (12-bit, 8 MSPS)
  -> RxIQCDC (clock domain crossing)
  -> DDC (tune + decimate 128x to 62.5 kSPS)  [reused from maia_hdl]
  -> C4FM Demod (FM discriminator)             [p25_hdl/c4fm_demod.py]
  -> Symbol Timing Recovery (Gardner TED)      [p25_hdl/symbol_timing.py]
  -> Dibit Packer (32 dibits -> 64-bit DMA)    [p25_hdl/dibit_packer.py]
  -> DmaStreamWrite -> DDR3 (HP3)              [reused from maia_hdl]
  -> PS reads via UIO
```

P25 Phase 1 C4FM: 4800 sym/sec, 12.5 kHz channel, 4FSK +/-1800/+/-600 Hz deviation.
AD9361: 8 MSPS (Tezuka BBPLL 1024 MHz / 4 = 256 MHz ADC / 32x HB = 8 MSPS exactly).
DDC: 128x (16x4x2) -> 62.5 kSPS -> ~13 samples/symbol.

## Register Map

| Offset | Register | Fields |
|--------|----------|--------|
| 0x00 | product_id | product_id (R, 32b, "p25f") |
| 0x04 | version | bugfix, minor, major, platform (R) |
| 0x08 | control | sdr_reset (RW) |
| 0x0C | interrupts | spectrometer, recorder, dibit_dma (Rsticky) |
| 0x10 | recorder_control | start, stop (Wpulse), mode (RW), dropped_samples (R) |
| 0x14 | recorder_next_address | next_address (R) |
| 0x20 | spectrometer | use_ddc_out, num_integrations, abort, last_buffer, peak_detect |
| 0x24 | ddc_coeff_addr | coeff_waddr (RW) |
| 0x28 | ddc_coeff | coeff_wren (Wpulse), coeff_wdata (RW) |
| 0x2C | ddc_decimation | decimation1, decimation2, decimation3 (RW) |
| 0x30 | ddc_frequency | frequency (RW, 28b) |
| 0x34 | ddc_control | operations_minus_one1/2/3, odd_operations1/3, bypass2/3, enable_input |
| 0x40 | demod_status | dibit_count (R, 16b), demod_overflow (Rsticky) |
| 0x44 | demod_control | start, stop (Wpulse), demod_enable (RW) |
| 0x48 | dibit_next_address | next_address (R, 32b) |
